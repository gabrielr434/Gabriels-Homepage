# Gabriel's Homepage

A personal portfolio website built as part of Harvard's CS50 course, showcasing core web development skills using HTML, CSS, JavaScript, and Bootstrap.

🔗 **Live site:** [https://gabrielr434.github.io/Gabriels-Homepage/](https://gabrielr434.github.io/Gabriels-Homepage/)

## About This Project

This site is a four-page personal homepage designed to demonstrate front-end web fundamentals:

- **Home** — a landing page with a hero section, an About preview, a stats row, and a rotating testimonials carousel
- **About** — a short bio page
- **Projects** — a showcase of other work, including a CS50 trivia quiz app
- **Contact** — a simple contact form

## Features

- **Responsive design** — built with Bootstrap's grid system, so the layout adapts cleanly across desktop, tablet, and mobile screens
- **Dark mode toggle** — a JavaScript-powered button that switches the site between light and dark color schemes
- **Scroll animations** — sections fade in smoothly as the user scrolls, using the JavaScript `IntersectionObserver` API
- **Bootstrap components** — navbar, cards, carousel, and icons integrated throughout
- **Custom styling** — a hand-written `styles.css` file layered on top of Bootstrap for a unique visual identity, including a custom Google Font (Poppins)

## Built With
